## 👋 نبذة

أنا **محمد علي طاهر**، وأنا من بنى هذه الأداة بالكامل من الصفر.

بدأت الفكرة من سؤال بسيط: كيف أعرض نظام إدارة أمن المعلومات وفق مواصفة **ISO 27001** بشكل عملي بدل أن يبقى مجرد نظرية في ملف PDF؟ كل بند في المواصفة يجب أن يكون له مكان يُسجَّل فيه، وشاشة تُعرض فيها حالته.

فقررت أن أبني **لوحة تحكم ويب** تُغطي الوحدات الست الأساسية للنظام، بواجهة عربية كاملة، تعمل **دون إنترنت**، وتُظهر مؤشرات قابلة للقياس لمدير الأمن.

### لماذا هذا المشروع بالتحديد؟

| الهدف | كيف حقّقته |
|-------|-----------|
| تطبيق عملي للمواصفة | كل وحدة مرتبطة ببند حقيقي من بنود ISO 27001 |
| واجهة عربية أصيلة | RTL كامل + تعريب كل القيم + أرقام لاتينية للفرز الصحيح |
| عمل دون إنترنت | نزّلت كل المكتبات محليًا بدل CDN |
| مؤشرات فورية للمدير | لوحة تحكم + تقارير تحليلية محسوبة من البيانات الحقيقية |
| حماية أساسية مدمجة | CSP، تحديد الطلبات، تحقق صارم من كل مدخل |

## ⚡ التشغيل السريع

### الطريقة الأسرع — بنقرة واحدة

انقر مرتين على **`Run.bat`**

هذا كل شيء. سيُفتح المتصفح تلقائيًا على `http://localhost:5000`.

> كتبت `Run.bat` بنفسي ليتولى كل شيء: البحث عن Node، تثبيت الاعتماديات عند الحاجة، فحص المنفذ، الانتظار حتى يصبح الخادم جاهزًا، ثم فتح المتصفح.

### الطريقة اليدوية

```bash
# 1) انتقل إلى مجلد المشروع


# 2) ثبّت الاعتماديات (مرة واحدة فقط)
npm install

# 3) شغّل الخادم
node server.js

# 4) افتح المتصفح
start http://localhost:5000
```

**المتطلب الوحيد:** [Node.js](https://nodejs.org) إصدار 16 أو أحدث (أنصح بـ 18 أو 20).

**لإيقاف الخادم:** اضغط `Ctrl + C` في النافذة.

## 🛠️ التحديات التي واجهتني وحلّيتها

هذا الجزء الأهم في مشروعي — كل تحدٍّ علّمني شيئًا:

### 1. التطبيق كان ميتًا بالكامل بسبب CDN
كانت القوالب تسحب jQuery و DataTables من الإنترنت. عند أول تشغيل **لم تعمل أي صفحة**. الحل: نزّلت كل شيء في `public/vendor/` وربطتها محليًا، ثم شدّدت CSP إلى `'self'` فقط. الآن تعمل الأداة **بدون إنترنت**.

### 2. Helmet كان يكسر التنسيق كله
Helmet يفعّل `upgrade-insecure-requests` افتراضيًا، وهو يحوّل روابط HTTP إلى HTTPS فيتكسر ملف `custom.css` على خادم محلي عادي. الحل: `upgradeInsecureRequests: null` مع توضيح السبب في تعليق.

### 3. الأرقام العربية كانت تكسر الفرز
`moment/locale/ar` يحوّل الأرقام إلى هندية (٢٠٢٦). النتيجة: DataTables كان يفرز التواريخ كنص لا زمنيًا. الحل: تجاوزت `preparse` و `postformat` لاستعادة الأرقام اللاتينية مع الإبقاء على صياغة الوقت النسبية بالعربية.

### 4. أخطاء `NaN` في الواجهة
طلب فارغ أو قيمة غير رقمية كانت تنتج `NaN × NaN = NaN` فيظهر شارة "NaN"، و `0/0` كان يعطي "NaN%". الحل: أضفت `numberIn()` و `percentage()` مع قيم بديلة آمنة.

### 5. تحديد الطلبات كان يعطّل التصفح
المحدِّد العام كان يحسب كل طلب CSS و JS وصورة، فبعد تصفح بسيط كان المتصفح كله يرجع `429`. الحل: حصرته في مسارات API والنماذج فقط.

### 6. ثغرة XSS في حقن JSON
`JSON.stringify` وحده لا يكفي — قيمة تحتوي `</script>` تُغلق الوسم. الحل: `jsonForScript()` الذي يحوّل `<` و `>` و `&` إلى تهريب `\u`.

### 7. التفاف الشريط الجانبي
كان `main` ينزل سطرًا تحت الشريط. السبب: `margin` زائد على الشريط. الحل: ضبط الهوامش و `width: calc()` في `custom.css` مع `!important` لضمان الأسبقية على Bootstrap.

### 8. `layout.ejs` قالب ميت
`server.js` لا يستخدمه. لم أحذفه لأنه مرجعUseful للقالب العام، وأبقيته متسقًا مع بقية القوالب.

## 🔍 استكشاف الأخطاء

### ❌ `Node.js was not found`
ثبّت Node.js 18+ من [nodejs.org](https://nodejs.org)، أو انسخ `node.exe` إلى داخل مجلد المشروع.

### ❌ `npm is not recognized`
موجود على هذا الجهاز فعليًا. **الحل: استخدم `Run.bat`** — يعمل بـ `node` مباشرة ولا يحتاج `npm` طالما كان `node_modules` موجودًا. أو شغّل `node server.js` مباشرة.

### ❌ `EADDRINUSE: address already in use :::5000`
```bash
netstat -ano | findstr :5000      # اعرف العملية
taskkill /PID <الرقم> /F          # أغلقها
# أو شغّل على منفذ آخر:
set PORT=8080 && node server.js
```

### ❌ المتصفح: "This site can't be reached"
انتظر ثانيتين، ثم جرّب فتح `http://localhost:5000/api/dashboard-stats` — يجب أن يعرض JSON، وهذا يثبت أن الخادم يعمل.

### ⚠️ البيانات تختفي عند الإغلاق
**سلوك مقصود.** لا توجد قاعدة بيانات — كل ما تضيفه يبقى في الذاكرة. عند إعادة التشغيل تعود البيانات الأولية. للاستخدام الأكاديمي هذا مناسب تمامًا.
